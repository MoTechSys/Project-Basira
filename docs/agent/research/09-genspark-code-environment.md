# 09 — بيئة Genspark Code: الدليل الرسمي مُدقَّقًا سطرًا سطرًا مقابل الواقع المقاس

> **المصدر:** «دليل Genspark Code — إصدار التطوير العام» (أرسله المالك 2026-10-01؛ لم يكن ضمن ما وصلتُ إليه بالبحث — بحثي وصل لصفحة Help Center العامة فقط). **المنهج:** كل ادعاء في الدليل يُقابَل بما قسناه في هذا الـ sandbox. علامات: ✅ مطابق · ⚠️ مطابق جزئيًا/يحتاج تدقيقًا · ❌ غير مطابق لهذا الـ sandbox.

## 2. «سير التطوير» (المخطط)
وصف ← توليد ← اختبار/معاينة ← يعمل؟ (لا → تصحيح → تحديث → عودة) (نعم → **احفظ** → GitHub / نسخة / نشر / تنزيل) ← مكتمل.
- ✅ يطابق بروتوكولنا لكن بروتوكولنا **يضيف** ما لا يذكره الدليل: مراجعة من عائلة نموذج أخرى، بوابات حتمية (ruff/mypy/pytest/smoke)، ADR/DECISIONS، تحديث الذاكرة بعد كل WP. الدليل يصف الحد الأدنى؛ نحن نعمل فوقه (S-D1 DORA: «AI amplifies what's already there»).

## 5. «القدرات الرئيسية» و«أفضل الممارسات المطبّقة»
- «Git، npm/pip/cargo/go mod، Make/webpack/vite، اختبارات، linting» — ✅ Git/npm/pip/Make مثبّتة؛ cargo/go mod/vite تُثبَّت عند الحاجة.
- «كود نظيف، توثيق، معالجة أخطاء، تحقق مدخلات، أمان» — الدليل يَعِد؛ **نحن نقيس**: `research/02–04` تحوّلها لقواعد قابلة للاختبار؛ `make gates` ينفّذها.
- «كوميتات منتظمة، رسائل ذات معنى، إدارة فروع، تاريخ نظيف، **سير عمل pull request**» — ⚠️ المالك قرر **D-001: لا PR، دمج مباشر**. الدليل يصف الافتراضي؛ قرار المالك يتقدم عليه.

## 6. «عناوين URL للخدمات» و«الاستمرارية»
- «خدمات الويب تحصل على URL عامة» — ✅ `GetServiceUrl(port)` → `https://<port>-<sandbox-id>.sandbox.novita.ai` (مُتحقَّق في `ENVIRONMENT_ANALYSIS.md §6.2`).
- «الكود يبقى متاحًا **أثناء الجلسة**… استمرار العمل **عبر الجلسات**» — ⚠️ الجملة الثانية تصح **فقط** إذا دُفع إلى GitHub (القسم 1 من الدليل نفسه يقول إن الصندوق يُحذف). لا تناقض إن قُرئت معًا: الاستمرارية عبر git لا عبر الصندوق.
