# معمارية «بصيرة»

## نظرة عامة

```
┌───────────────────────────────────────────────────────────┐
│                     المستخدم (معرِّف بالإسلام)             │
└────────────────────┬──────────────────────────────────────┘
                     │ لصق نص / رفع صورة
                     ▼
┌───────────────────────────────────────────────────────────┐
│                   Frontend (React)                         │
│  - صفحة الفحص                                              │
│  - عرض الحالات الأربع                                      │
│  - تظليل الفروق حرفاً بحرف                                 │
└────────────────────┬──────────────────────────────────────┘
                     │ POST /v1/check
                     ▼
┌───────────────────────────────────────────────────────────┐
│                 Backend (FastAPI)                          │
│                                                            │
│  ┌─────────────────────────────────────────────────────┐  │
│  │  1. Extract (استخراج الاقتباسات)                     │  │
│  │     ↓ (LLM structured output)                        │  │
│  │  2. Retrieve (استرجاع المرشحين)                      │  │
│  │     ↓ (BM25 + Fuzzy)                                 │  │
│  │  3. Match (مطابقة حتمية)                             │  │
│  │     ↓ (strict + loose + harakat)                     │  │
│  │  4. Decide (قرار الحالة)                             │  │
│  │     ↓ (state machine)                                │  │
│  │  5. Verify (مدقّق لاحق)                              │  │
│  │     ↓ (post-validator)                               │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                            │
│         ┌────────┐    ┌────────┐    ┌────────┐             │
│         │ Tanzil │    │  OHD   │    │Hadeeth │             │
│         │ (قرآن) │    │(أحاديث)│    │  Enc   │             │
│         └────────┘    └────────┘    └────────┘             │
└────────────────────┬──────────────────────────────────────┘
                     │ JSON response
                     ▼
                 Frontend
```

## المبادئ

1. **Deterministic matching**: المطابقة حتمية، ليست احتمالية.
2. **No generation**: النموذج لا يولّد نصاً شرعياً.
3. **Explicit states**: 4 حالات واضحة لا تختلط.
4. **Post-validation**: مدقّق لاحق يرفض أي مخرج ملوّث.
5. **Source traceability**: كل نتيجة لها مصدر قابل للتتبع.

## الطبقات

| الطبقة | المسؤولية | التقنية |
|---|---|---|
| UI | عرض وتفاعل | React + TypeScript |
| API | HTTP interface | FastAPI |
| Pipeline | تنسيق الخطوات | Python |
| Extract | استخراج الاقتباسات | LLM (JSON schema) |
| Retrieve | البحث عن المرشحين | BM25 + fuzzy |
| Match | المطابقة الحتمية | Python (pure) |
| Verify | التحقق النهائي | Python (pure) |
| Corpus | إدارة المصادر | Python + SQLite |

## خارج النطاق

- ❌ لا تخزين لنص المستخدم.
- ❌ لا تحليل دلالي/معنوي.
- ❌ لا إفتاء ولا تصحيح/تضعيف أحاديث.
- ❌ لا توليد نصوص شرعية.
