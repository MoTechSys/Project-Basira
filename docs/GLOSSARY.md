# المصطلحات — بصيرة

## المصطلحات التقنية

| المصطلح | المعنى |
|---|---|
| **Corpus** | المدوّنة؛ مجموعة النصوص المرجعية (قرآن + حديث) |
| **Extract** | استخراج الاقتباسات من نص المستخدم (LLM) |
| **Retrieve** | استرجاع المرشحين من المدوّنة (بحث) |
| **Match** | المطابقة الحتمية حرف بحرف |
| **Verify** | المدقّق اللاحق (post-validator) |
| **Snapshot** | ملف محلي للمدوّنة مُعبّأ مسبقاً لإقلاع سريع |
| **Rate Limit** | حد عدد الطلبات في الدقيقة لكل IP |

## المصطلحات الشرعية (كما نستخدمها في المنتج)

| المصطلح | المعنى في «بصيرة» |
|---|---|
| **اقتباس** | نص منقول من مصدر شرعي (آية، أو متن حديث) |
| **المتن** | نص الحديث نفسه (بدون سند) |
| **الإسناد** | سلسلة الرواة (قبل المتن) |
| **التخريج** | نسبة الحديث إلى مصدره وتقييم صحته (شأن المختص، ليس شأننا) |
| **الرسم العثماني** | الشكل الكتابي المعتمد لمصحف المدينة |
| **التشكيل** | الحركات (فتحة، ضمة، كسرة، سكون، شدة، تنوين) |

## حالات التحقق الأربع

| الحالة | المعنى الدقيق |
|---|---|
| `found` | النص موجود حرفياً في المدوّنة بعد التطبيع المتفق عليه |
| `partial_match` | النص قريب لنص مدوّن لكن فيه فرق محدّد قابل للعرض |
| `not_found` | لا يوجد في مدوّنتنا — **ليس حكماً بعدم صحته** |
| `needs_review` | غموض يحتاج قراراً بشرياً (تشكيل مختلف، إسناد بلا متن، إلخ) |

## ما لا نستخدمه (محذورات لغوية)

| ❌ لا نستخدم | ✅ نستخدم بديلاً |
|---|---|
| "صحيح" أو "ضعيف" (من إنتاجنا) | ننقل حرفياً من مصدر مرخّص |
| "خطأ" أو "تحريف" | "فرق عن المدوّنة" أو "لم يُطابق" |
| "فتوى" أو "حكم شرعي" | خارج النطاق كلياً |
| "النص الصحيح هو..." | "في المدوّنة: ..." |
