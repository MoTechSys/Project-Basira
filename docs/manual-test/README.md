## هـ) الصور (`images/`) — قارئ الصور **حقيقي** الآن (gpt-5.4 عبر مفاتيح المنصة)
> سياسة ثابتة (ADR-003): أي اقتباس مصدره صورة **لا يأخذ «وُجد» أبدًا** حتى لو طابق حرفيًا — لأن قارئ الصور قد «يصحّح» الخطأ سرًا (حدث فعلًا: قرأ «علي» على أنها «على»). النتيجة دائمًا «يحتاج مراجعة — نص من صورة» مع عرض **النص كما قُرئ** لتتأكد منه بنفسك، ومع عرض المطابقة للمقارنة. الصور تأخذ 5–15 ثانية.
