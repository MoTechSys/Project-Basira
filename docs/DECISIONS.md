# قرارات التصميم — بصيرة

> سجل القرارات المعمارية الرئيسية. كل قرار له ADR (Architecture Decision Record) منفصل.

## الفهرس

- **D-001**: الحالات الأربع لنتائج التحقق (`found` / `partial_match` / `not_found` / `needs_review`)
- **D-002**: المطابقة الحتمية (deterministic) وليست الاحتمالية
- **D-003**: الفصل بين الاستخراج والمطابقة (LLM لا يولّد نصاً مرجعياً)
- **D-004**: لا تخزين لبيانات المستخدم
- **D-005**: مدقّق لاحق مستقل (post-validator)
- **D-006**: Tanzil مصدراً وحيداً للقرآن
- **D-007**: Rate limiting لحماية التكلفة

## قالب ADR

كل قرار يُسجّل في `docs/adr/NNNN-slug.md` بالصيغة:

```
# ADR-NNNN: عنوان القرار

## السياق
ما المشكلة؟ ما القيود؟

## القرار
ما الذي قرّرناه؟

## البدائل المرفوضة
ما الذي رفضناه ولماذا؟

## النتائج
ماذا يترتب؟
```
