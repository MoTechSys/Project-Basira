# ADR-0001: نموذج الحالات الأربع

## السياق
نحتاج تمثيل نتيجة فحص اقتباس شرعي. الاحتمالات العملية:
- مطابقة كاملة
- مطابقة فيها فروق
- لا مطابقة
- غموض يحتاج قراراً بشرياً

نموذج `boolean` (صح/خطأ) غير كافٍ ويضيّع معلومات.

## القرار
نعتمد 4 حالات صريحة ومتباينة:
- `found`: مطابقة حرفية 100%
- `partial_match`: مطابقة مع فروق محدّدة (مع إظهارها)
- `not_found`: لم يوجد في مدوّنتنا (ليس حكماً بالعدم)
- `needs_review`: يحتاج مراجعة بشرية

## البدائل المرفوضة
- **boolean**: مُختزل ويخفي معلومات مهمة.
- **score 0..1**: يوحي بثقة إحصائية مضلّلة في موضوع ديني.
- **5 حالات أو أكثر**: تعقيد بلا فائدة واضحة.

## النتائج
- واجهة المستخدم تعرض 4 بطاقات مميّزة بألوان.
- API يرجع `status` بأحد القيم الأربع فقط.
- اختبارات الوحدة تغطّي الحدود بين الحالات.
