# ADR 0003 — BYOK (Bring Your Own Key) للموفّرين

- الحالة: مُعتمد
- التاريخ: 2026-10-06
- الكاتب: MoTechSys

## السياق
المشروع يستخدم موفّري LLM/Vision اختياريين (OpenAI-compat) لتوليد البنية (لا النص الشرعي).
نحتاج طريقة لتشغيل الخدمة في بيئات لا نثق فيها بمفاتيحنا (sandbox / third-party demo).

## القرار
نقبل مفتاح الموفّر عبر header `X-Basira-Provider-Key` لكل طلب:
- لا يُسجّل أبداً
- لا يُحفظ على القرص
- يُمسح من الذاكرة بعد انتهاء الطلب
- التمرير إلى الموفّر مباشرة عبر httpx بدون تخزين وسيط

## البدائل المرفوضة
1. مفتاح واحد مركزي → خطر تسريب + لا يصلح لاستخدام متعدد المستخدمين
2. OAuth per-provider → تعقيد زائد في نافذة الهاكاثون

## العواقب
- (+) عرض آمن للمحكّمين دون كشف مفاتيحنا
- (−) على المستخدم جلب مفتاحه الخاص للـ demo الكامل
- (+) تناسب ممتاز مع نموذج MCP اللاحق
