# بصيرة (Basira)

> أداة تحقق لنصوص القرآن والحديث للمعرِّفين بالإسلام.

مشاركة في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026** — المسار الرابع: أدوات المعرفة والتحقق.

## الفكرة

تلصق نصاً أو ترفع صورة منشور، فتقوم «بصيرة» بـ:
- استخراج كل اقتباس قرآني أو حديثي.
- مطابقته حرفياً مع المصادر المرخّصة (Tanzil للقرآن، كتب الحديث المعتمدة).
- عرض الحالة لكل اقتباس: **وُجد** / **مطابقة جزئية** / **لم يوجد في مصادرنا** / **يحتاج مراجعة**.

**ضوابط صارمة:**
- لا تُفتي، ولا تصحّح الأحاديث، ولا تولّد نصوصاً شرعية.
- كل نص معروض يأتي من مصدر موثّق بإصداره ومعرّفه.
- التقييم في النشر النهائي عمل بشري.

## الهيكلة

## المصادر المعتمدة
انظر `SOURCES.md` للقائمة الكاملة مع هاشات SHA-256.

## للعرض (Demo pitch, 5 دقائق)

1. **المشكلة** — المعرِّفون بالإسلام يحتاجون التحقق السريع من الاقتباسات القرآنية/الحديثية قبل النشر.
2. **الحل** — بصيرة تُعيد لكل اقتباس حالة من أربع: FOUND / PARTIAL_MATCH / NOT_FOUND / NEEDS_REVIEW مع مرجعية موثّقة.
3. **الفارق** — مطابقة حتمية، لا إفتاء، fail-closed على المصادر المعتمدة فقط.
4. **العرض الحي** — إدخال نص مختلط (آية صحيحة + حديث منسوب خاطئ) ومشاهدة التصنيف الفوري.
5. **الطريق قدماً** — إضافة لغات، MCP integrations، لوحة للمتابعة.
